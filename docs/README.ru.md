# clockrate — регулировка механических часов по аудиозаписи

По записи звука часов, сделанной на телефон, измеряет **на сколько секунд в сутки часы спешат или отстают** и **амплитуду**, а также подсказывает, **в какую сторону и насколько сдвинуть регулятор (стрелку градусника)**.
При каждой записи результат сохраняется в историю, и по сравнению с предыдущей записью вычисляется, «в какую сторону и какую долю прошлого сдвига» нужно повторить.

Инструмент создан при регулировке будильника Slava 5671 (18000 bph), но подходит для любых механических часов с тикающим звуком (частота задаётся через `--bph`).

Примеры реальных записей и результатов проверки есть в [`examples/`](examples/README.md).

## Установка

Требуется [ffmpeg](https://ffmpeg.org/) (`sudo apt install ffmpeg`, `brew install ffmpeg` и т. п.).

```bash
pip install -e .            # clock-rate 명령 설치
pip install -e '.[test]'    # 테스트까지
```

Можно также запускать без установки: `python3 -m clockrate ...`.

## Порядок регулировки часов

```bash

                          # 2. 안내대로 조속 레버를 옮기고 다시 녹음
clock-rate 녹음2.m4a      # 3. 직전 녹음과 비교해 다음 이동량 안내
```

### Критерии оценки

| Оценка | Суточная погрешность | Значение |
|---|---|---|
| ◎ Регулировка завершена | в пределах ±10 с (изменяется `--tolerance`) | Больше не трогайте |
| △ Рекомендуется тонкая подстройка | в пределах ±30 с | Сдвиньте совсем немного |
| ▲ Требуется регулировка | в пределах ±60 с | |
| ✖ Сильное отклонение | больше | |

- **Погрешность боя (beat error)** — асимметрия интервалов между тиком и током. До 3 мс — хорошо; больше 5 мс — стоит выставить баланс в положение покоя (бой).
- **Амплитуда** — угол поворота баланса за одно колебание. Более 330° — слишком много (осторожно, близко к банкингу/клеванию), 250–330° — хорошо, 200–250° — удовлетворительно, менее 200° — низкая (проверьте завод пружины, смазку, загрязнение) — по критериям, обычно применяемым к наручным часам. См. [Амплитуда](#амплитуда).
- **Стабильность хода** — разброс значений, посчитанных отдельно по фрагментам записи длиной 10–20 с. Большой разброс означает, что пружина развивается, часы двигались или запись плохого качества.
- **Надёжность измерения** оценивается только по качеству записи (длина, доля обнаруженных тиков, шумовые щелчки). При «низкой» надёжности выводятся причина и советы по записи.
- **Следующий сдвиг** — оценка, основанная на предположении, что изменение хода пропорционально величине сдвига регулятора. Если по сравнению с предыдущей записью почти ничего не изменилось, инструмент предупредит, что регулятор мог провернуться вхолостую или спираль баланса (волосок) вышла из штифтов регулятора.

| `results/<имя_файла>/진단.png`, `소음제거.wav` | Только при `--diagnostics`: шумоподавление, состояние обнаружения тиков, позиции unlock/drop для расчёта амплитуды |

**Как читать таймграфер:** для каждого тика точкой откладывается, на сколько (мс) он опередил номинал.
- **Наклон линии:** точки идут вверх — часы спешат, вниз — отстают.
- **Серый сектор:** целевой диапазон (±10 с/сутки). Линия внутри него — цель достигнута.
- **Расстояние между двумя рядами:** промежуток между рядами тиков (синие) и токов (оранжевые) — это погрешность боя.

## Амплитуда

В звуке одного тика наложено несколько коротких звуков. В швейцарском анкерном спуске (включая Slava 5671) сначала идёт **unlock** (слабый звук освобождения спуска), затем **drop** (громкий звук падения зуба).
Пока баланс поворачивается на угол подъёма, проходит время между этими двумя звуками, поэтому амплитуду можно вычислить:

```
진폭 = 리프트각 / (2·sin(π · 언락→드롭 시간 / 한 주기))
```

- **Усреднённая кривая:** огибающие громкости всех тиков и токов накладываются друг на друга, берётся медиана, и самый выраженный пик перед drop в физически возможном диапазоне (время, соответствующее амплитуде 140–380°) считается unlock.
- **Надёжность:** 95%-й интервал получается бутстрепом (случайная перевыборка тиков). Если значения для тика и тока различаются более чем на 30° или интервал шире 40°, результат помечается «для справки».
- **Угол подъёма:** характеристика конкретного механизма. Официальное значение для Slava 5671 найти не удалось, поэтому по умолчанию стоит типичные для швейцарского анкера 52°. Абсолютное значение настолько же неопределённо, насколько это допущение.
- **Сравнение одних и тех же часов:** амплитуда почти пропорциональна углу подъёма, поэтому сравнение записей одних часов (уменьшилась ли амплитуда) точно независимо от угла подъёма. Эту тенденцию видно на графике истории регулировки.
- **Диагностический график:** с `--diagnostics` видно, какие именно звуки приняты за unlock и drop.

## Несколько часов

С `--multi-clock` инструмент также находит другие часы, попавшие в запись (например, кварцевые настенные часы в комнате), и измеряет их суточную погрешность. Без этой опции результат в точности такой же, как раньше.

```bash
clock-rate recordings/오버홀하루후.mp3 --여러시계
```

```
 ▶ 다른 시계 (--여러시계)
   시계 2   1.000초 간격 · 실측 3599.9 bph · 쿼츠 시계(1초마다 뛰는 초침)로 보임
            오차 범위 안 (사실상 정확)   (-1.3 ± 2.9 초/일)
            틱 177/180개 사용 (98%) · 틱 시각 흔들림 11.2 ms · 800–1500 Hz 대역에서 찾음
            주 시계 − 시계 2: -1.9 ± 4.3 초/일 (녹음 장비 시계 오차와 무관)
```

- **Как ищется:** диапазон 200 Гц–12 кГц делится на пять полос, в каждой строится огибающая громкости, и из неё в позициях, предсказанных моделью ритма основных часов, вычитается форма их тиков (медианная по двухтактовым окнам). В автокорреляции остатка ищется периодичность от 0,1 до 2,5 с; в самой выраженной полосе обнаруживаются тики, и суточная погрешность вычисляется той же моделью ритма, что и для основных часов. Найдя одни часы, инструмент вычитает и их, и ищет дальше (максимум 3).
- **Отсечение ложных часов:** найденная периодичность должна быть выраженнее остаточных повторов основных часов (кратных их периоду), должно обнаруживаться не менее 70% ожидаемых тиков, а дрожание моментов тиков — не более 5% периода.
- **Определение кварцевых:** интервал 1 с (3600 bph) трактуется как кварцевые часы со стрелкой, шагающей каждую секунду.
- **Основные часы − другие часы:** оба механизма измеряются по одним и тем же часам записывающего устройства, поэтому погрешность часов телефона в эту разность не входит. Взяв за эталон кварцевые часы (обычно ±0,5 с/сутки), получаем погрешность основных часов без участия телефона.
- **Точность:** фоновые часы звучат тише, дрожание моментов тиков у них велико (единицы — десятки мс), поэтому при той же длине записи доверительный интервал шире, чем у основных часов. Интервал расширяется умножением ошибки регрессии на поправку, учитывающую корреляцию соседних остатков (использовать разброс по окнам, как у основных часов, нельзя: наклон в каждом окне неточен, и ошибка чрезмерно раздувается).
- Другие часы не включаются в историю регулировки и сравнение со спецификацией.

## Спецификации

Если записать спецификацию механизма в INI-файл в `sheets/` и передать её через `--sheet`, инструмент по каждому пункту проверит, укладывается ли измерение в заводской допуск.

```bash
clock-rate 녹음.m4a --시트 sheets/slava_5671.ini
```

```
 ▶ 사양 비교 — Slava 5671 (61М): 측정 가능한 항목 모두 공차 안 (경계 1개)
   ◎ 합격    하루 오차         -3.2 ± 1.1 초/일       사양 ±60초/일
                          근거: «Суточный ход механизма ±1 мин при температуре +20±5°С»
   △ 경계    진폭            약 301°               사양 180–310°
   · 측정 불가 파워 리저브        —                    사양 36시간 이상
   ...
```

- **Критерии оценки:** если измеренное значение и его 95%-й интервал целиком в допуске — **проходит**; если значение в допуске, а интервал выходит за его границу — **на границе**; если значение вне допуска — **не проходит**. Амплитуда «для справки» (где тик и ток различаются) не оценивается однозначно и отмечается как «на границе».
- **Неизмеримые пункты:** запас хода, разница погрешности при разном заводе пружины, колебания амплитуды, автоматический пуск — по одной записи не измерить; для них выводится «не измеряется» и способ измерения.
- **Отображение основания:** комментарий после `;` за значением в спецификации выводится в результате как «основание». Оставляйте источник спецификации.
- **`sheets/slava_5671.ini`:** спецификация Slava 5671 и нормы регулировки (суточная погрешность ±1 мин, диапазон регулятора ±3 мин, амплитуда 180–310°, запас хода не менее 36 ч и т. д.) перенесены с цитатами из книги Л. В. Шамоновой «Ремонт механических будильников» (1987). Для угла подъёма и допуска погрешности боя в оригинале чисел нет, поэтому поля оставлены пустыми.
- **`sheets/_template.ini`:** пустой шаблон для других механизмов.

## Советы по записи

- В тихой комнате плотно приложите микрофон телефона к задней крышке часов.
- Записывайте **не менее минуты**. Короче 20 секунд — точность заметно падает, а стабильность хода не оценивается.
- В зависимости от степени завода пружины ход может отличаться на десятки секунд в сутки. Для сравниваемых записей сохраняйте одинаковые условия.

## Принцип работы

1. **Шумоподавление:** полосовой фильтр 3,5–16 кГц, затем спектральный гейтинг. Опорный шум берётся из тихих участков между тиками, а медиана по временной оси в 1-секундных окнах отслеживает медленные изменения шумового фона (разговоры, телевизор, звуки движения рук).
2. **Оценка периода ритма:** берётся наиболее часто встречающийся интервал между пиками огибающей громкости (в терминах обработки сигналов — «envelope»). Даже если тики чередуются сильный/слабый, несколько тактов не принимаются за один.
3. **Первичное обнаружение тиков:** фиксируется момент, когда огибающая впервые превышает 30% высоты пика.
4. **Нумерация тактов и удаление помех:** тики последовательно нумеруются по тактам; шумовые щелчки, выпадающие из ритма, отбрасываются.
5. **Точная коррекция:** для тиков и токов строится усреднённая форма (шаблон), и взаимная корреляция каждого тика с шаблоном уточняет момент с субдискретной точностью. Пропущенные тики восстанавливаются поиском в предсказанной позиции звука, достаточно похожего на шаблон (корреляция ≥ 0,6). На зашумлённых записях дрожание моментов тиков снижается примерно на 60%.
6. **Модель ритма:** методом наименьших квадратов решается `t = a + n·박간격 + c·(홀짝)`. Член чётности — это погрешность боя.
7. **Амплитуда:** измеряется время unlock→drop в исходном звуке (до гейтинга) и вычисляется амплитуда (см. [Амплитуда](#амплитуда)).
8. **Суточная погрешность:** `(номинальный период / измеренный период − 1) × 86400`. Доверительный интервал — большая из двух величин: ошибка регрессии и разброс значений по временным окнам. Из-за медленных флуктуаций самих часов одна ошибка регрессии дала бы слишком узкий интервал.

## Проверка

На синтетических записях из `tests/` (городской шум, звук регулятора, погрешность боя, чередование сильных/слабых тиков, звук unlock) суточная погрешность совпадает с эталоном в пределах 0,5 с/сутки, амплитуда — в пределах 8°.
На синтетической записи с тихим кварцевым тиком (1 кГц) на фоне `--multi-clock` находит суточную погрешность кварцевых часов в пределах 1 с/сутки от эталона, а на записях без других часов (включая чередование сильных/слабых тиков) не находит ничего.
На реальной записи (Slava 5671) значение инструмента (+8,4 ± 0,6 с/сутки) совпало с измерением Android-приложения таймграфера (+7 с/сутки).
Реальный случай регулировки (22–23.10.2026): Slava 5671, спешивший на 14 мин 43 с в сутки, по подсказкам инструмента был отрегулирован изменением рабочей длины спирали и положения регулятора до **+0,6 с/сутки** (измеренные 18000,1 bph; перекрёстная проверка по фоновым кварцевым часам +3,4 ± 28,7 с/сутки). Ход работ описан в [`docs/slava_5671_regulation_notes.ru.md`](docs/slava_5671_regulation_notes.ru.md).
