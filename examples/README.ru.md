# Примеры

Реальные записи будильника Slava 5671, сделанные на телефон, и результаты их проверки с помощью `clock-rate`.

## Записи (`recordings/`)

| Файл | Длительность | Ситуация |
|---|---|---|
| `탈진기.mp3` | 15 с | Рычаг регулятора дважды сдвинут во время записи (пример автоматического разбиения по звукам рычага) |
| `시간조정.mp3` | 60 с | После одного сдвига рычага |
| `시간조정2.mp3` | 64 с | После дальнейшего сдвига рычага |
| `시간조정3.mp3` | 121 с | После слишком сильного сдвига в сторону отставания (запись, где громкость тиков чередуется сильная/слабая) |
| `시간조정4.mp3` | 26 с | После возврата назад (короткая запись с большим количеством шумовых щелчков) |
| `직접오버홀.mp3` | 121 с | После самостоятельной разборки, чистки и смазки, с полностью заведённой пружиной |

## Результаты проверки (`results/`)

В каждом каталоге есть `리포트.png`, `요약.txt` и `요약.json`, причём сводка включает сравнение со спецификациями из `sheets/slava_5671.ini`.
`직접오버홀/진단.png` показывает структуру звука, использованную для шумоподавления, обнаружения тиков и расчёта амплитуды.
`조정기록.png`/`조정기록.json` — история регулировки в порядке 시간조정 → 직접오버홀.

## Как воспроизвести

Из корня репозитория:

```bash
E=examples/results
clock-rate examples/recordings/시간조정.mp3 examples/recordings/시간조정2.mp3 \
           examples/recordings/시간조정3.mp3 examples/recordings/시간조정4.mp3 \
           --시트 sheets/slava_5671.ini --출력 $E
clock-rate examples/recordings/직접오버홀.mp3 --시트 sheets/slava_5671.ini --진단 --출력 $E
clock-rate examples/recordings/탈진기.mp3 --분할 자동 --기준 구간1 --이름 가운데,한쪽끝,반대쪽끝 \
           --시트 sheets/slava_5671.ini --기록끔 --출력 $E
```

С опцией `--진단` также создаётся `소음제거.wav`, который из-за размера не включён в примеры.
